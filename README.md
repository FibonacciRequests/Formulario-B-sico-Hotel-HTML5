
Formulario de Opinión de Hotel

	Descripción
	
	Este proecto consiste en un formulario web que permite a los
	huespedes de un hotel compartir su experiencia durante
	su estadía
	
	Características
	
	-Registro de información personal del huesped
	-Validación de campos obligatorio
	-Selección de opciones mediantes botones de radio
	-Selección múltiple mediante casillas de verificación
	-Calificación del servicio y la comida
	-Campo de texto para cometarios adicionales
	
	Tecnologías utilizadas
		
	-HTML5
